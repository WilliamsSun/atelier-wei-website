# Atelier WÉI — Personal Archive

这是一个参照 entropic.group 交互方式制作的个人网页，发布文件位于
`dist/`。页面包含固定 75px 网格、居中的 Logo 与介绍文字、可拖动图片、图片坐标标注、点击 Logo 重置布局和手机预览。

## 启动

使用任意静态文件服务器将 `dist/` 作为根目录，例如：

```text
http://127.0.0.1:8765/index.html
http://127.0.0.1:8765/mobile-preview.html
```

## 图片命名规则

将图片放入 `dist/images/`，文件名使用：

```text
(x,y)_width_annotation.ext
```

例如：

```text
(110,320)_1950_Nanjing 南京.jpg
```

- `x`、`y` 是图片注释黑底方框左上角相对于网格坐标原点的初始坐标；原点为第四根横线与页面左侧第一根竖线的交点。
- `width` 是图片在 2560px 电脑端的横向宽度。
- 下划线后的文字是图片标注，会显示在图片上方的黑底方框中。
- 其他设备按照 `当前可用网页宽度 ÷ 2560` 等比例缩放坐标和图片宽度。
- 图片 Y 坐标使用同一个宽度基准，不会因图片数量增加或页面变长而偏移。

图片路径在 `dist/data.js` 的 `window.IMAGE_SOURCES` 中维护。删除文件后，页面加载失败的图片会自动从画布移除。

## 页面交互

- Logo 悬停或键盘聚焦时运行平滑动效。
- 点击 Logo 会清除保存的拖动位置，并恢复所有图片的文件名初始坐标。
- 拖动图片后，位置保存到浏览器 `localStorage`；标注文字保持不变。
- 点击图片不会打开弹窗；拖动图片时会自动提升到最上层。
- `mobile-preview.html` 提供 393 × 852 的 iPhone 16 预览。

## 视觉基准

Logo、米字参考线、顶部介绍文字和底部文字都以网页屏幕中心为锚点。网格在横向固定、纵向随页面内容延伸；Logo 和文字会随页面滚动离开顶部视口。
